How it works

  1. We ask NASA's IRSA archive which SPHEREx exposures cover your position.
  2. Your browser reads only the few hundred pixels it needs from each 62 MB file in NASA's public cloud copy, instead of downloading it.
  3. Each exposure is turned north-up and lined up to a fraction of a pixel using its own sky calibration.
  4. Exposures from one survey pass are averaged, so faint things rise out of the noise. Subtract two passes and everything that stayed put disappears.

What it cannot do

  • One SPHEREx pixel is 6.15″ wide. A shift smaller than about a third of a pixel is hard to see by eye, so we measure it instead.
  • Each exposure sees a given spot at a single wavelength, so brightness changes from image to image even for a steady star. Compare stacked passes to judge real change.
  • A planet as faint as the proposed Planet Nine is far below what one exposure reaches. This tool shows the method working on known movers. It does not claim a discovery.
